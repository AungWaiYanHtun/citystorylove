CITYSTORYLOVE - CHARACTER WALKING / DEPTH UPDATE

Preserves the original tropical island artwork, buildings, resources, save data,
menus, and existing game features. The four residents keep their established
character identities and use the 32 directional PNG files in:
  island-assets/characters/

Character updates:
- Uses front, back, left, and right artwork for each resident.
- Alternates the two walking poses using elapsed time rather than frame count.
- Enlarges the four residents so they remain visible at the full-island mobile
  zoom level.
- Sorts people and buildings using their ground-contact screen Y, so a person
  can correctly appear behind a building instead of always drawing over it.
- Chooses roaming destinations with spacing from other residents to reduce
  overlapping/spawning on top of each other.

Movement updates:
- Keeps movement on the lawn, sandy path, and dock/beach walking area.
- Uses A* pathfinding around placed buildings and mapped natural obstacles.
- Checks the initial connection to the path grid and every grid segment.
- Prevents diagonal corner cutting and keeps intermediate route cells.
- Fisher beach points are checked against the walkable area.

Checks performed:
- Node.js syntax check for the updated island-game.js.
- All 32 expected directional PNG files exist and decode successfully.
- Pathfinding harness checked all 342 ordered routes among 19 valid island
  patrol points with the default buildings; no returned route crossed a
  non-walkable segment and no valid-point route was missing.
- ZIP archive integrity check.

Not performed: a complete live Android / Netlify play-through. Test on a
staging copy before replacing the live site.
